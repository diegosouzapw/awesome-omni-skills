## Review prompts

- Which themes attract the right buyers?
- Which CTAs create real replies or DMs?
- Which posts create only vanity engagement?
- Which prospects engaged but were never followed up?
- Which content should be repurposed into a DM resource or proof asset?

## Decision rules

- Double down on themes that generate qualified conversations.
- Rewrite or retire themes that only generate broad engagement.
- Add explicit follow-up ownership for ICP engagement.
- Match future content to real buyer questions observed in DMs or calls.
