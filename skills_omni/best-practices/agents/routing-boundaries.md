# Routing Boundaries

Use this note to decide whether `best-practices` is still the right skill.

## Stay in this skill when

- the task is mainly about web security hygiene
- the task is mainly about compatibility or modernization of frontend patterns
- the task is mainly about code-quality issues visible in browser-facing code
- the user wants focused findings or safe fixes in those areas

## Hand off when

- accessibility is a primary deliverable
- SEO is a primary deliverable
- performance or Core Web Vitals is the main goal
- the user wants a broad multi-area web audit
- the work becomes deep application security testing beyond best-practices scope

## Handoff guidance

When handing off, pass along:

- what was already checked
- evidence already collected
- unresolved risks
- whether any changes were already applied
