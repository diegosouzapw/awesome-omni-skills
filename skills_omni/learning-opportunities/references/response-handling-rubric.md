# Response Handling Rubric

Use this rubric after the learner responds.

## Correct

**Signal:** The user accurately explains the behavior or design choice.

**Response move:**

- confirm briefly
- add one nuance, constraint, or variation
- reconnect to the relevant code

**Template:**

```text
Yes. That's right. The extra thing to notice is ____. You can see that in `path/to/file` where ____.
```

## Partially correct

**Signal:** The user has the main direction right but misses an important distinction.

**Response move:**

- name what is correct
- correct one key gap
- avoid piling on extra lessons

**Template:**

```text
You're right that ____. The missing piece is ____. In `path/to/file`, that matters because ____.
```

## Incorrect

**Signal:** The explanation does not match actual behavior.

**Response move:**

- be direct that it is incorrect
- explain the actual behavior clearly
- ground the explanation in code or tests

**Template:**

```text
Not quite. What actually happens is ____. The evidence is in `path/to/file` where ____.
```

## Guessed but useful

**Signal:** The answer is uncertain but reveals a workable mental model.

**Response move:**

- acknowledge the reasoning effort
- refine the model with one correction

## Skipped

**Signal:** The user says skip or asks for the answer.

**Response move:**

- stop the exercise
- give a concise direct explanation
- tie it back to the current task

## Disengaged

**Signal:** The user ignores the prompt, redirects to shipping, or signals impatience.

**Response move:**

- exit teaching mode
- continue with delivery work
- do not offer again unless the user reopens the topic
