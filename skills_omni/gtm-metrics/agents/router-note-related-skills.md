# Related Skill Router Note

Use this note when the request is adjacent to GTM metrics but no longer centered on measurement design.

## Stay in `@gtm-metrics` when

- the task is selecting KPIs
- the task is designing dashboards or scorecards
- the task is defining metric formulas, owners, or source of truth
- the task is diagnosing attribution, data quality, pipeline inspection, retention measurement, or AI unit economics

## Hand off when

### Route to `@ai-pricing`
- packaging, monetization, pricing tiers, usage pricing design, or willingness-to-pay become the main decision

### Route to `@ai-sdr`
- SDR workflow design, meeting-booking process, outbound sequencing, or qualification operations become the main task

### Route to `@ai-cold-outreach`
- messaging, copy, channel experimentation, or campaign execution become the main work

## Boundary reminder

Do not turn this skill into a warehouse, BI, CRM-admin, or instrumentation implementation guide. It is for measurement strategy, governance, and operating cadence.
