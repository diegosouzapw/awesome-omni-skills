# Handoff Router

Use this router when the request moves beyond motion design.

## Route to Pricing Skill

Use when the task becomes:
- packaging design
- tier construction
- monetization mechanics
- discounting or contract structure

## Route to Outbound / SDR Skill

Use when the task becomes:
- outbound sequence creation
- persona messaging
- campaign execution
- reply handling

## Route to RevOps / Analytics Skill

Use when the task becomes:
- event instrumentation
- CRM workflow design
- dashboard implementation
- attribution modeling

## Route to Technical Implementation Skill

Use when the task becomes:
- building onboarding flows
- implementing product analytics
- changing application code
- integrating billing or CRM systems

## Route to Legal / Compliance Review

Use when the task becomes:
- contractual review
- security assurances
- privacy or regulatory interpretation
