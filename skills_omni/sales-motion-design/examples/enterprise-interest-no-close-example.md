# Example: Enterprise Interest but No Close

## Scenario

A developer tool has strong bottom-up usage inside large companies, but enterprise deals rarely close.

## Findings

- users prove technical value
- economic buyers join late
- security and admin requirements surface only near the end
- no clear owner manages procurement or rollout planning

## Recommendation

- shift the enterprise segment toward **sales-assisted PLG**
- preserve self-serve entry for users
- create a buyer-facing proof path covering security, admin, and rollout
- define enterprise PQLs around sustained domain usage and admin/security intent
- train sales to engage on expansion and procurement blockers, not generic feature recap
