# Example: Low Activation Diagnostic

## Scenario

A self-serve analytics product has healthy signup volume but poor paid conversion.

## Findings

The real problem is not pricing. New users land in an empty dashboard and must connect data sources before seeing any insight.

## Recommendation

- define activation as "first dashboard with usable insight generated"
- preload sample data
- guide users to one setup path instead of many options
- measure signup-to-data-connect and data-connect-to-first-insight separately
- postpone pricing changes until activation improves

## Why this matters

If users never reach value, changing free-to-paid mechanics will not fix the motion.
