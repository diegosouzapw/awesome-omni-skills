# Example: Founder-Led to Hybrid

## Scenario

A seed-stage B2B workflow SaaS has:

- founder-led inbound sales
- growing self-serve signups
- multiple teams from the same company appearing in product usage
- deals stalling when buyers ask for admin controls and rollout help

## Diagnosis

- product can create value without a live demo
- usage signals appear before buyers talk to sales
- human help becomes useful after activation, not before it

## Recommendation

- move toward **PLG + sales hybrid**
- keep self-serve onboarding as the entry path
- define PQLs around multi-user/team behavior and enterprise-control intent
- use sales for rollout, security, procurement, and plan selection

## Initial KPIs

- activation rate
- median TTFV
- PQL rate
- PQL-to-close
- CAC payback by segment

## First experiments

1. Define two PQL thresholds and compare close rates.
2. Add an enterprise-readiness path inside the product.
3. Delay rep outreach until after activation or second-team signal.
