# Playwright Skill Router

Use this note when deciding whether `playwright-skill` is still the right tool.

## Stay with this skill when

- the task is scripted browser automation
- you need screenshots or browser-based evidence
- you need to validate a user flow in a browser
- you need repeatable interaction against a web UI

## Route to another skill when

### Route to `@chrome-devtools`

When the user wants:

- live DOM/CSS inspection
- console debugging
- network waterfall inspection
- interactive browser debugging
- performance profiling

### Route to `@documentation`

When the main deliverable is:

- a test plan
- a runbook
- an evidence summary
- structured QA documentation

### Route to `@architecture`

When the task becomes:

- CI test strategy
- environment design
- long-term test architecture
- cross-team automation planning

### Route to `@find-skills`

When browser automation is no longer the best fit and a different capability is needed.
