# Example test plan for key user journeys

## Goal

Audit representative journeys instead of testing only one page.

## Selected journeys

1. Sign in
2. Password reset
3. Site search with filters
4. Add to cart and checkout
5. Account profile update

## For each journey, verify

- keyboard completion without mouse
- visible and unobscured focus
- headings and landmarks are meaningful
- every control has an accessible name
- form labels, instructions, and errors are announced correctly
- dynamic updates are announced appropriately
- mobile or touch interaction remains usable where relevant

## Evidence to save

- route or screen name
- issue count by severity
- screenshots or DOM snippets for key defects
- whether issue was found automatically or manually
- whether fix was re-tested successfully
