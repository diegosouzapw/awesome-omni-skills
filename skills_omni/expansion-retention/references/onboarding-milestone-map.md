# Onboarding Milestone Map

Use this map when churn concentrates in the first 30 to 90 days.

## Milestones

| Window | Goal | Evidence of success | If missed | Typical owner |
| --- | --- | --- | --- | --- |
| Day 0 | Account setup completed | account created, access confirmed | recovery or setup support | Product or onboarding |
| Day 1-7 | First value reached | first core workflow completed | guided activation | onboarding or CS |
| Day 7-30 | Habit formation | repeat usage, team adoption, integration completion | milestone rescue plan | CS |
| Day 30-90 | Outcome realization | ROI signal, workflow embedded, stakeholder alignment | executive or manager review | CS + account owner |

## Intervention rules

- If setup is incomplete, reduce friction before adding more nurture.
- If first value is delayed, identify the blocked step and intervene specifically.
- If one user activates but the team does not, add collaboration or stakeholder plays.
- If usage is present but outcomes are unclear, add value proof and education.

## Segment note

- Enterprise onboarding usually needs project visibility and stakeholder mapping.
- SMB and self-serve onboarding usually need simpler milestone automation and clearer in-product guidance.
