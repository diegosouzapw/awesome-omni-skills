# Puzzle Activity Review Criteria

Use this quick rubric to review a proposed puzzle activity before handoff.

## How to Use

Score each category:

- **2 = ready**
- **1 = partly ready / needs revision**
- **0 = missing or risky**

A strong plan usually scores at least **12/16**, with no zero in Safety, Accessibility, or Instructions.

---

## 1. Audience Fit

Check:
- age range is stated
- reading level is reasonable for the audience
- content and references are age-appropriate
- group size and social format match the activity design

Red flags:
- clue wording assumes adult vocabulary for children
- solo worksheet used for a high-energy party group
- competitive format used for a group that needs low-pressure participation

## 2. Goal Alignment

Check:
- the plan states whether the goal is fun, review, team-building, or themed engagement
- puzzle types support that goal
- challenge level matches the intended outcome

Red flags:
- novelty tools selected before defining the activity purpose
- lesson-review request answered with unrelated trivia puzzles
- team-building request answered with mostly solo tasks

## 3. Instructions and Plain Language

Check:
- participants can tell how to start
- instructions are chunked into steps
- one example or model is included when needed
- facilitator notes separate rules from answers

Red flags:
- challenge comes from confusing wording rather than the puzzle itself
- multiple hidden assumptions in the launch script
- participants must infer how submission or checking works

## 4. Difficulty and Timing

Check:
- estimated solve time range is given
- difficulty is named or implied clearly
- there is a hint ladder or support plan
- there is an extension or early-finish option

Red flags:
- no hinting strategy
- all-or-nothing challenge with no fallback
- total planned activity time equals best-case solve time with no transition buffer

## 5. Accessibility and Inclusion

Check:
- font, contrast, and layout are considered for print or digital use
- the activity does not rely only on color, speed, or heavy writing unless intended and acceptable
- an easier path, alternate format, or paired-play option exists
- timing pressure is adjustable when needed

Red flags:
- tiny print or cluttered worksheet
- instructions too dense for the stated age group
- clue solving depends on fast reading or memory overload
- only one participation mode is possible

## 6. Safety and Supervision

Check:
- supervision assumptions are explicit
- physical movement is safe for the space
- small parts or props are appropriate for the audience
- internet access, if required, is appropriate for the setting

Red flags:
- free-form scavenger hunt with children and no supervision note
- hidden items, sharp tools, or choking hazards for young participants
- direct recommendation to use external sites with minors and no adult review note

## 7. Materials and Logistics

Check:
- required materials are listed
- setup effort is realistic
- print count or device assumptions are clear
- answer key exists and is usable

Red flags:
- plan assumes printers, locks, or devices not mentioned in intake
- answer key missing
- multiple station props required with no setup guidance

## 8. External Link Hygiene

Check only if links or generators are included:
- each link is labeled as optional or verify-before-use
- login/data/ad concerns are considered
- printability or mobile usability is checked
- generated output quality is reviewed before sharing

Red flags:
- link shared as if automatically approved
- no note on ads, login, or student suitability
- generator output not reviewed for clue quality or answer key

---

## Decision Guide

### Approve
Use when:
- no critical gaps remain
- safety and accessibility are acceptable
- the activity can be run with the stated materials and time

### Revise
Use when:
- the core idea is sound but one or more categories scored 1
- the plan needs simpler wording, better timing, or a fallback option

### Stop / Re-scope
Use when:
- the plan has a zero in Safety, Accessibility, or Instructions
- the audience or context is too unclear to make a responsible recommendation
- third-party tools are central but cannot be verified

---

## Quick Improvement Prompts

If a plan is weak, ask:
- What is the minimum reading load needed?
- What happens if the group stalls in the first 3 minutes?
- What is the easier version of this same idea?
- Can the puzzle be completed without relying only on color, speed, or internet access?
- Is there an answer key and a realistic timing buffer?
- Would an adult facilitator understand exactly when to hint, pause, or stop?
