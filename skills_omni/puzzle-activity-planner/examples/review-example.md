# Worked Example: From Vague Request to Reviewed Puzzle Plan

## User Request

"I need some puzzle activities for a 4th grade class next week. It should be fun and educational, around 30 minutes, and maybe include online generators if that helps."

## Step 1: Intake Clarification

Collected details:

- **Audience:** 4th grade, mixed reading levels, 24 students
- **Context:** classroom
- **Goal:** vocabulary review plus collaboration
- **Duration:** 30 minutes total
- **Format:** printable preferred; projector available; student web browsing not preferred
- **Materials:** printer, pencils, scissors, envelopes
- **Accessibility needs:** two students benefit from simplified instructions; one student should avoid time pressure
- **Supervision:** teacher-led
- **External links:** acceptable for teacher prep, not for direct student use

## Step 2: Initial Weak Draft

Weak draft:

- Give students a hard crossword and a cipher.
- Use online generators.
- Split into groups.
- Winner gets a prize.

## Why the Weak Draft Fails

- no explicit learning target
- no timing estimate
- no accommodation plan
- no answer-key note
- external tools mentioned without verification limits
- challenge level likely too high for mixed reading levels
- competition introduced without checking whether that suits the classroom goal

## Step 3: Reviewed Planning Table

| Field | Decision |
| --- | --- |
| Goal | Vocabulary review with cooperative solving |
| Activity style | 3 short puzzle stations in rotating groups |
| Difficulty | Easy start, medium middle, easy win finish |
| Timing | 5 min intro, 18 min stations, 5 min debrief, 2 min buffer |
| Materials | Printed sheets, envelopes, pencils, scissors |
| Accessibility | plain-language directions, optional oral readout, untimed completion for one group if needed |
| Link policy | Teacher may use generators for prep only; verify answer key and print layout before class |
| Fallback | Replace cipher with matching puzzle if students stall |

## Step 4: Final Plan

### Activity Summary

**Title:** Vocabulary Puzzle Rotation  
**Audience:** 4th grade classroom, 24 students  
**Goal:** reinforce current vocabulary through cooperative puzzle solving  
**Duration:** 30 minutes  
**Format:** printable, teacher-led station rotation

### Puzzle Lineup

1. **Word Match Relay**
   - Students match vocabulary words to plain-language definitions
   - **Time:** 6 minutes
   - **Difficulty:** easy
   - **Purpose:** quick success and topic activation

2. **Mini Crossword Review**
   - Short crossword using current vocabulary only
   - **Time:** 6 minutes
   - **Difficulty:** medium
   - **Purpose:** recall spelling and meaning

3. **Sequence the Clues**
   - Students arrange sentence clues in the correct order to reveal a final answer phrase
   - **Time:** 6 minutes
   - **Difficulty:** easy-medium
   - **Purpose:** collaboration without heavy writing load

### Facilitation Notes

- Divide into 3 groups of 8
- Start with a 1-minute example showing how answers should be recorded
- Rotate every 6 minutes
- Offer one hint per station after 3 minutes if a group is stalled
- End with a brief debrief: "Which clue type helped you remember the words best?"

### Accessibility Adjustments

- Print in large, high-contrast text
- Read instructions aloud before starting
- Keep definitions in plain language
- Allow one group to complete without rotation pressure if needed
- Pair stronger and less confident readers deliberately
- Avoid clues that depend only on color coding

### Safety and Suitability Notes

- Seated classroom activity; no hidden objects or movement search
- Scissors used only for teacher prep, not student handling during play
- No direct student use of third-party websites

### Optional Prep Tools

Teacher may use a crossword or matching-sheet generator during preparation, but only after checking:

- answer key exists
- puzzle uses classroom vocabulary only
- printable layout fits the page
- no login or ads are required during student use

## Step 5: Troubleshooting Adjustment

### Observed Risk

The original idea included a cipher puzzle.

### Review Decision

Dropped for this audience because the 30-minute session and mixed reading levels make early frustration more likely than productive challenge.

### Replacement

Used a sequencing puzzle instead, which still supports problem solving but lowers decoding burden.

## Good Outcome Signals

- students can begin within the first minute
- every station has a clear finish condition
- the teacher knows when to hint
- no student must use a website during class
- the plan can be run with normal classroom materials

## Reusable Pattern

For elementary classroom requests:

- prefer 2 to 4 short puzzles over 1 long puzzle
- use an easy first win
- choose collaboration over elimination
- keep generators in the teacher-prep layer, not the student-execution layer
